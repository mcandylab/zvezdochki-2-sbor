Подключение к GitHub

Чтобы менять отметки, нужен отдельный ключ доступа. Он разрешит изменять только файлы этого репозитория.

  1. Создайте Fine-grained access token.
  2. В Repository access выберите Only select repositories → zvezdochki-2-sbor.
  3. В Permissions → Repository permissions → Contents выберите Read and write.
  4. Создайте ключ и вставьте его ниже.

Ключ действует только в этой вкладке и удаляется после её закрытия. Он не сохраняется в репозитории.
